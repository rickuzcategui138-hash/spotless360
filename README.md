# Spotless360 — Website

Marketing website for **Spotless360**, Atlanta's trusted experts for **air duct, dryer vent, chimney and gutter cleaning & repair**.

## Stack

Static site — plain **HTML, CSS and vanilla JavaScript**. No build step required.

```
spotless360/
├── index.html      # Home page
├── styles.css      # Brand styles (green + gold, Poppins/Inter)
├── script.js       # Mobile nav + small interactions
└── assets/         # Logo and media
```

## Run locally

Any static server works, for example:

```bash
python -m http.server 5501
```

Then open http://localhost:5501
